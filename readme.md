Flashker Ultimate Vocabulary Flashcards Leaning App

--

This fishy app is made by Ivan to study vocabulary. Because all flashcard apps I tried were simply shit. Version 1.0.3. Codename: Flounder.


Please read what this app is and what this app is not before you come complaining. More explanation to be added soon. You have to understand how to use the app to get the most out of it. Swipe left = wrong. Swipe right = correct. If you get a card wrong, it will reappear sooner. If you use the "spaced repetition" mode, this replicates the normal behaviour of most other flashcard apps. Swipe left, and the card will appear sooner. Swipe right, and it will be due after a longer duration. If you use the "IVAN" mode engine, the idea is that you have to try to go through the words as many times as you can and as quickly as you can, if possible you should not even need to flip them, just swipe left or right. The main idea is to rely on rote memory. The trick is to memorize the words by high repetition. Research the science - I have not, but I know it works for me. It is my own custom algorithm. I will explain better sometime in the future.


The code was fully developed from scratch, and it is all my own work except some vibe-coding here and there (yes, I checked the vibe).
